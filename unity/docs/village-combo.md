# 村のコンボと建設費

村のホームの生産施設は、上下左右に接する同種施設1棟につき、1回の加工で得られる数量を25%増やす。隣接する両方の施設に適用し、斜めや間が空いた施設は数えない。2×2マスを使う生産施設では、配置座標が上下左右に2マス離れた位置が対象となる。

| 隣接する同種施設 | 生産量の倍率 |
|---|---|
| 0棟 | ×1 |
| 1棟 | ×1.25 |
| 2棟 | ×1.5 |
| 3棟 | ×1.75 |
| 4棟 | ×2 |

施設ごとに隣接数を数える。2棟を並べると両方が1.25倍になり、2×2に4棟並べると各施設が1.5倍になる。倉庫や増幅所など、品目を生産しない施設は対象外とする。

加工時間・材料・ガス消費はコンボで変えない。エフォートは既存どおり加工速度とガス消費を変えるため、毎分の生産量には速度とコンボの倍率が掛かる。生産レポートの理論生産量と実績にも反映する。

## 端数と加工途中の扱い

1回の基本生産量が1個の場合、1.25個のうち整数分を生産し、残りの0.25個を次回へ持ち越す。同種施設が1棟隣接していれば、4回の加工で合計5個になる。端数は施設ごとに保持し、移設と再起動でも保持する。ガス不足・材料不足・出力満杯で加工を開始できないときは端数を進めない。

生産数量と端数は加工開始時に確定する。加工途中に施設を建設・移設しても支払済みの数量と終了時刻は変えず、次の加工から新しい配置を使う。確定した数量は保管容量の予約にも含め、投入・入庫・施設群の追加生産と合わせて容量を判定する。

通常のコンボは表示のズームに依存しない。既存の施設群による別品目の追加生産は、コンボとは別に動作する。

## コンボの表示

盤面では、同種施設の間に矢印のない紫の短い線を引く。施設を選ぶと、その施設につながる線と相手の足元の枠を強調する。倍率の札は施設詳細を開く入口にもなり、ガス不足や満杯の表示と併せて確認できる。

施設詳細は下から画面の半分まで開くパネルとし、コンボ・エフォート・在庫までパネル内をスクロールして確認する。コンボ欄は、中央に現在の倍率と成立方向数を置き、上下左右に「成立 +25%」または「未成立」を表示する。4方向がそろった施設は「4方向成立・最大 ×2」と表示する。周囲の施設を移動すると、成立状況と倍率を更新する。

建設・移設で有効な場所を選んだときは、配置候補とその周囲についてコンボを見積もる。候補につながる線と配置後の倍率を表示し、周囲の施設の倍率変化も操作欄に示す。移設では元の位置から施設を除いた配置で計算する。プレビューで生産状態は変更せず、取り消すと現在の村の表示へ戻る。

## 種類別の建設費

次の建設に必要な電気は、施設の基本建設費に、その種類の累計建設数を加えた値とする。漁場なら電気10、11、12と増える。別種類を建てても漁場の費用は増えない。水の基本建設費は変えない。

成功した建設だけを数える。移設や失敗した建設では増えず、撤去しても累計数を減らさない。資源無限のモードでも建設数を記録し、通常に戻したときはその数に対応する費用を使う。施設一覧とクイック建設欄には、実際に支払う次回の費用を表示する。

## 保存と移行

保存の版は5。`ComboSchema`、種類別の累計建設数、施設ごとの加工中の生産数量と端数を保存する。保存に失敗した建設は、施設・資源・累計建設数を反映しない。

旧保存では、現在ある施設数を種類別の累計建設数の初期値とする。過去に撤去した施設数は旧保存に記録がないため復元しない。旧保存の加工中の分は、コンボ適用前の数量で完了し、次回から新しい配置を使う。

`VillageComboTests`、`VillageComboUiTests`、`VillageComboWorldTests` で隣接判定、端数、費用、容量予約、加工途中の移設、保存・復元、保存失敗、四方向の図、狭い画面の配置、盤面の線、プレビューと取り消しを検査する。
