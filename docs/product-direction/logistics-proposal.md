# 組み合わせと倉庫の提案

作成日: 2026-10-24。以下は設計の比較・検討用で、実装済みでも採用済みでもない。[製品方針](README.md)で確認済みの内容を前提に、区画と物流の扱いを提案する。

## 前提

施設は、自分が材料として使わない鉄などの資源も中継できる。倉庫は物流の複雑な調整を自動で行い、利用者による細かな配送設定を基本にしない。上位資源は下位施設の材料には使わず、中継する。

土地の拡張単位は2×2マスと決まっている。以下の固定区画の提案では、拡張区画と組み合わせ区画の境目をそろえることを推奨する。2×2単位の拡張と、固定の組み合わせ区画を採用するかどうかは別の判断になる。

「倉庫4棟を組み合わせると大型倉庫になり、輸送が速くなる」は検討案。移動時間・距離の単位・輸送量の数値はまだ決まっていない。

## 不規則な配置の区切り方

点を1施設とし、左端をそろえた上段2棟・下段3棟の配置を想定する。違う配置を意図している場合は、以下の図の前提を見直す。

```text
提示された形     施設名を付けた形
..               A B
...              C D E
```

推奨案は、盤面をあらかじめ重複しない2×2の区画に分ける方式。図の左上が区画の起点で、A〜Dが組み合わせ条件を満たす場合は、次のようになる。

```text
下位の配置                 1段階上の表示
┌───┬───┐
│A B│・ ・│               ┌─────┬───────┐
│C D│E ・│       →       │上位建物X│未完成区画 │
└───┴───┘               │       │Eの存在を表示│
                         └─────┴───────┘
・は空きマス
```

A〜Dを上位建物Xとして表示する。Eは右隣の未完成区画に残り、生産・中継を続ける。未完成区画は新しい上位建物にならず、そこを開けばEを編集できる。5棟すべてを無理に1棟へまとめたり、余ったEを消したりしない。

EとXの物流は、元のDとEの隣接を引き継ぐ案とする。上位の表示で区画同士が接していても、下位で存在しなかった輸送経路は増やさない。ズームだけで品物の通れる場所が変わらないようにする。

固定区画なら、3×3に施設が埋まった場合なども、複数の2×2が同じ施設を取り合わずに判定できる。一方、区画の境目をまたぐ2×2は組み合わせられない。その制約を分かるように、建築・移設中は区画の境目と成立する組み合わせを表示する。

好きな2×2を選ぶ方式も可能だが、重複候補の選択・解除・さらに上の階層への対応を別途決める必要がある。まずは固定区画を試作し、配置の制約が遊びに合うか確かめることを提案する。

## 普通の施設と倉庫の違い

普通の施設もすべての種類の資源を中継できるため、単に「資源を通せる」だけでは倉庫を置く理由になりにくい。輸送量と一時保管に違いを持たせる案を提案する。

| 施設 | 提案する役割 | 配置する理由 |
|---|---|---|
| 普通の施設 | 生産に加えて、少量の資源を中継する | 小さい工場は生産施設を並べるだけで動く |
| 倉庫 | 多くの資源を中継し、一時保管しながら自動配送する | 分岐や大量輸送で、普通の施設だけの経路より流れを改善できる |
| 大型倉庫 | 倉庫4棟の組み合わせとして、より多くの資源を短い時間で扱う | 物流拠点に土地を使う価値と、組み合わせによる成長を作る |

輸送の速さは「届くまでの時間」と「一定時間に運べる量」に分けて考える。初期の試作では、施設1マスの移動を距離の基本単位にし、まず運べる量の違いを試す案とする。遠いほど到着が遅くなる表現は別途検討し、速度と輸送量を同じ値だと扱わない。

大型倉庫の効果は、その倉庫を通る経路に適用する案を推奨する。離れた場所に置くだけで島全体が速くなる効果は前提にしない。内部の倉庫4棟の能力と上位の能力をどう合わせるかは未決で、同じ輸送を二重に数えないようにする。

大型倉庫は、新しい品物を生む代わりに物流能力を強化する組み合わせの候補になる。通常の上位建物が別資源を生産する方針に対し、倉庫は機能が強化される例外としてよいかを確認する。

## 自動配送の判断

利用者が行うのは工場と倉庫の配置。送り先・優先順位・確保量を細かく入力させる方式は基本にしない。配送を自動化する際の候補は次のとおり。

1. 稼働を予定している工場のレシピから、必要な資源と不足量を調べる。
2. 必要な資源を持つ施設から、実際に隣接してつながる経路で送る。距離だけでなく、輸送能力と混雑も候補にする。
3. 同じ資源を複数の工場が必要とする場合は、不足状況を見て配分する。近い工場だけが受け取り続けないようにする。
4. 材料がそろっている施設への過剰配送を抑え、送り先が満杯なら倉庫で一時保管する。

これは判断方法の提案であり、工場全体の生産量が最大になることを保証するものではない。生産目標や輸送制約が決まってから、何を改善する自動配送なのかを定義する。

操作を減らしても、配送先・配送中の量・材料不足・輸送の混雑は確認できるようにする。利用者が、倉庫を置いた結果と、次に改善できる配置を理解できるかを試作で確かめる。

## 階層をまたぐ資源

上位資源は、下位施設を通過しても材料として使われず、下位資源にも変化しない。上位資源の消費先を探す際は、その資源を使える生産レシピを持つ施設だけを対象にする。

中継経路が下位施設を含む場合でも、資源の種類と出発元・配送先を保つ。階層を下げて表示したことを理由に、新しい消費先や輸送経路を作らない。

下位施設を通過する際の輸送能力、上位建物の出入口と内部4棟の対応、移設・組み合わせ解除の途中にあった貨物の扱いは未決。これらを確定してから、上位と下位の物流を一体として実装する。
