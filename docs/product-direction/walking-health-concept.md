# 歩行と工場の効率化を組み合わせる設計案

更新日: 2026-10-24。健康促進を目的としたゲーム設計の補足案。数値・費用計算・実装構成は検証用であり、製品への採用は未確定。

## 目的

工場の非効率を、歩いて得たガスの追加投入で補えるようにする。同じ納品目標に対して、配置を改善して燃料を節約する方法と、歩いて燃料を増やす方法を用意する。両方を組み合わせてもよい。

歩行量を施設の保有条件にせず、生産を進めるための資源として扱う案である。ガス不足では新しい出荷・加工を待機させ、施設や在庫を失わせない。既に燃料を支払った処理は完了できるようにする。

## 製品方針との関係

[製品方針](README.md)にある、隣接する施設と倉庫による自動配送、2×2の組み合わせ、週ノルマを置き換える文書ではない。

比較用の物流モデルでは施設別在庫と明示的な経路を扱うが、手動で線を引く操作を製品の基本操作にするという意味ではない。線を表示する場合はRectTransformを使い、物流の計算と表示を分ける。

ガスを施設運用、電気を建設、水を土地拡張に使う役割分担を候補とする。水の使用・維持費がどこで発生し、効率化でどれだけ減るかは未決である。

## 比較する攻略方法

| 方法 | 行動 | 検証したいこと |
|---|---|---|
| 効率化 | 施設と物流経路を改善する | 同じ完成品に必要なガスが減るか |
| 資源の追加投入 | 歩数からガスを得る | 非効率な配置を残しても、燃料を補うことで達成できるか |
| 組み合わせ | 改善しながら燃料も補う | 設計と日常の行動がどちらも攻略に役立つか |

効率を「完成品1個を倉庫へ届けるまでに使うガス」で比較する。稼働していない施設や、材料不足・満杯で待つ施設ではガスを消費しない案とする。

## 検証用の数値

原料4個を加工し、倉庫へ4個届ける小さなモデルを使う。製品の物流方式が決まる前に、燃料量の違いを比較するための仮設定である。

| 項目 | 非効率な配置 | 効率的な配置 |
|---|---|---|
| 原料・加工・完成品の数量 | いずれも4個 | いずれも4個 |
| 2区間の配送費 | 1個につき各2ガス | 1個につき各1ガス |
| 加工費 | 1個につき1ガス | 1個につき1ガス |
| 目標までの合計 | 20ガス | 12ガス |
| 500歩で1ガスの場合の換算 | 10,000歩分 | 6,000歩分 |

500歩で1ガス、基礎付与20ガス/日は既存クライアントの値を使った比較案。新しい製品の換算率は未決であり、健康上の推奨歩数を表すものではない。増幅や他の取得経路は、この比較では適用しない。

この上限では10,000歩以降の歩行は追加ガスにならない。常に歩けば不足を解決できるわけではないため、目標量・上限・換算率を合わせて評価する。上限を維持するか、変更するか、取得量を段階的に減らすかは別途決める。

## 表示する情報

ガス残高、歩数の取得状態、その日に受け取ったガス、完成品1個あたりの費用、目標への到着数を表示する。配送と加工の所要時間も示し、燃料を得れば直ちに納品が終わると誤解させない。

追加歩数を表示する場合は、既に支払った配送・加工費を除き、目標までに今後必要なガスから計算する。未接続・容量不足・日次上限が原因なら、それぞれの理由を示す。取得失敗を0歩と表示しない。

## 未決事項

| 論点 | 決める内容 |
|---|---|
| 効率化の対象 | 経路の長さ、中継回数、まとめて運ぶ量、加工レシピのどれを費用へ反映するか |
| 初期資源 | 初回の歩数取得前や取得できない端末でどう始めるか |
| 水と電気 | 拡張・建設・改修への支出と、蓄積した資源の使い道 |
| 週ノルマ | 集計対象、期間境界、通常納品との関係、達成不能時の扱い |
| 報酬 | 超過分から得る特殊資源の換算、ペンギン解放との関係、省エネなどの永続強化を追加するか |

健康への効果は未検証。攻略の理解、効率化による節約、歩行で燃料を補う動機、上限により進めない頻度を評価する。
