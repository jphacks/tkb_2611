# 所持型の収集効果を資源フローへ加えるときの考え方

更新日: 2026-10-24。[資源フローの知識](principles.md)を、所持しているだけで効くペンギンの設計へ適用した検討メモ。外部のゲームでこの数値が実証されているとは主張しない。

## 加算と乗算

基礎獲得量をB、加算率をA、乗算倍率をMとすれば、獲得量はB×(1+A)×M。加算は割合を合計し、乗算は合計後に1回掛ける。基礎量100、加算5%、乗算1.05なら110.25になる。

固定の付与量を受取1回ごとに加えると、記録や受取を分割するだけで得をする可能性がある。生産バッチが小さい施設と大きい施設の比較も変わるため、今回の案では基礎量に対する割合を加算する。

## 同種を集める意味と上限

現行案では、同種n羽の加算率を a×n、倍率枠を 1＋b×n とする。aとbは対象次数で変える。例えばR4はa＝1、b＝0.20なので、各1羽で×2.4、各10羽で×33。0羽ならどちらも補正なしになる。

旧案の半減と1.21倍の上限は使わない。上位の要求量を桁で増やし、施設と所持数も成長する案へ変更した。aとbが正なら、同じ資源の両種を増やす効果は二次的に伸びる。各個体の倍率をそのままn乗する方式より伸びを抑えるが、固定の上限があるわけではない。将来の次数を追加する際は要求量との比較をやり直す。

## 生産網への波及

魚の増量は、魚の直接納品だけでなく、すり身・干物を作れる量にも影響する。さらにすり身や完成品にも増量があれば、段階をまたいだ効果が重なる。ただし材料の比率・エネルギー・加工能力・配送のどれかが律速になるため、全工程の倍率を掛けた値を実際の生産量にはできない。

速度上昇、1バッチの出力増加、エネルギー節約は異なる。今回の案は同じバッチ時間・材料・エネルギーで出力を増やすため、品物1個あたりの累積コストも下がる。以前のバランス計算はペンギン効果なしの基準として残し、所持数ごとの比較は別に扱う。

## 再付与を防ぐ境目

現実由来のエネルギーは付与時、品物は生産完了時に増量する。同じ品物を倉庫・中継・納品の各段階で増量すると、経路によって量が変わり、循環させるだけで増える危険がある。保存からの再開にも、同じ生成イベントの効果を再適用しない。

基礎量0は補正後も0。加算の割合と小数の繰越は表示上の丸めと分け、受取回数で総量が変わらないようにする。R0の上限の判定と、ペンギン補正の適用順も明示する。

## 次に確かめること

ペンギンなし、各種1羽、各種10羽の初回生産を分け、補給の偏りも比較した。[現行の検証](progression-review.md)を参照する。各種10羽は効果の感度を見る仮定で、遭遇確率から予測した通常の所持数ではない。収集による継続動機や、すれ違いの少ない環境での体験は数量計算では確認できない。
