# 90秒プレゼン原稿（たたき台）

80秒の動画に合わせて話し、最後の10秒は工場の全景とタイトルを静止表示する。時間配分は目安。

## 0〜30秒｜背景と課題

映像：工場の全景→資源の採取・加工・自動化

「あなたの生活によって、攻略が変わる工場ゲームを作りました。

FactorioやSatisfactoryのような工場ゲームでは、資源を集め、加工する設備をつなぎ、生産を自動化します。どう組み合わせれば効率よく作れるか、考えるのが魅力です。

ただ、効率を求めるうちに、定番の攻略をなぞってしまうこともあります。そこで、私たちは資源の集め方を変えました。」

## 30〜50秒｜現実から得られる資源

映像：歩数・スクリーンタイム・水の記録→資源→使い道

「このゲームでは、歩数からガス、スマホを使わなかった時間から電気、水分補給の記録から水を得ます。

ガスは工場の稼働や増産に、電気は施設の建設に、水は土地の拡張に使います。生活によって、得られる資源の量と比率が変わります。」

## 50〜80秒｜プレイヤーによる攻略の違い

映像：同じ生産目標に対して、増産する工場と増設する工場を比較

「例えば、同じ生産量を目指す場合でも、よく歩く人は、豊富なガスで今ある施設の生産量を伸ばす。

電気が豊富な人は、施設を増やし、同じ施設を並べるボーナスを狙う。

どの資源を使い、どこに投資するか。自分の生活に合った工場を考えます。

同じ人でも、たくさん歩いた日には、いつもと違う進め方を選べます。」

## 80〜90秒｜締め

映像：動画を終え、工場の全景とタイトルを静止表示

「あなたの日常によって、工場の育ち方が変わります。

このゲームで、あなただけの工場を作ってみませんか？」
